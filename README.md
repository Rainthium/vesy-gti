# Единая весовая система ГП «ГТИ»

Система управления автомобильными весами на 13 объектах ГП «Таможенная Инфраструктура»: центральный сервер + агенты на весовых компьютерах. Принимает команды взвешивания от АИС «СВХ», хранит журнал взвешиваний и фото, работает автономно при потере связи. Заменяет UniServer AUTO.

## Структура (целевая)

```
dev/
├── agent/      # служба весового ПК: драйверы, цикл взвешивания, камеры, локальный веб, синхронизация
├── center/     # центральный сервер: API АИС, WS-сервер агентов, панель, БД
├── shared/     # общие модели сообщений и перечисления
├── tools/      # эмулятор индикатора, служебные скрипты
└── docs/       # документация разработки
```

Стек: Python 3.12, FastAPI, PostgreSQL (центр), SQLite (агент), HTMX/Jinja2, docker-compose.
