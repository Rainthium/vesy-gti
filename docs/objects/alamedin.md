## Весовой индикатор

- Протокол **«CAS 22 byte»** — конфиг WeightIndicator1 **байт в байт совпадает с Кызыл-Кыёй** (синхробайты `2C 2C 2C 0D 0A` по адресам 2/5/8/20/21, масса — строка в байтах 9–16, флаг стабильности `ST` в байтах 0–1, без CRC, без команд запроса/инициализации/обнуления). Драйвер `agent/drivers/cas22.py` подходит без изменений; модель самого индикатора (шильдик) не снята — при установке сфотографировать для реестра.
- Порт **COM4** — PCI-E карта WCH (COM3/COM4 + LPT3; COM3 свободен), не USB-переходник: зависаний CH340 тут не будет. 9600 8-N-1, управление потоком None, DTR/RTS не поднимать. Переоткрытие порта в UniServer выключено; тайм-аут «нет данных» 3000 мс, ответа 100 мс.
- Дискретность **10 кг**, kg, 0 знаков, множитель 1; НмПВ 20 дискрет (200 кг).
- **Параллельная работа с UniServer — через TCP, без com0com** (19.08.2026): драйвер com0com на этом ПК не грузится (`sc start com0com` → 577, ошибка подписи; Windows 11 26200 — та же сборка, что на К-К, но там драйвер встал). В UniServer настроен модуль **SERIALTCPIP1**: `Mode=Server`, `Host=127.0.0.1`, `Port=4001`, `SourceRepeaterSerialPort=SerialPort_WI1` — поток с COM4 дублируется в `127.0.0.1:4001` (проверено: `netstat` LISTENING, в PowerShell читаются пакеты `ST,GS,…`). Агент читает `port = "socket://127.0.0.1:4001"` — для этого понадобилась сборка **0.4.20** (в 0.4.19 замороженный exe не знал протокол socket://, см. decisions 19.08). Урок: кнопка «Перезапуск сервера» в вебе UniServer уронила его насовсем — поднят `sc start UniServerAuto`; перезапускать только службой.
- В журнале UniServer много строк «Автофиксация после съезда» с весом 120–240 кг — `AutoScale1.glob_AutoFixingMode=1` (на К-К 0); Игорю показано, где выключить. У нас такого механизма нет.
- Весы по реестру — ЮУВЗ «Соболь» 80 т (статические, полный заезд). В UniServer тип весов Normal, режим НЕТТО **Double** (два взвешивания; на К-К — AutoTara), период актуальности тары UniServer 30 дней (для нас неважно: тару даёт реестр тарирований центра, правило №4), автосоздание документа Never, автофиксация незафиксированных проездов включена.

## Камеры (из выгрузки, 19.08.2026)

Две IP-камеры, слоты Camera3/Camera4 пустые → фото на взвешивании — 2 шт. По URL старого хиквижн-формата, OSD «Camera 01» и дате «…-1970 Tue» — **Hikvision (или OEM) 6 МП**, поток **3200×1800 @ ~15 к/с** (K-K: 2560×1440).
