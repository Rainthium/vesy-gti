# Контракт API v1 — АИС «СВХ» (совместимый)

Статус: действующий формат снят с боевой интеграции; расширения (`operation`, `tare`, `netto`) **ожидают подтверждения разработчиками АИС** — см. PROGRESS «Вопросы к Игорю».

## Команда взвешивания (АИС → центр)

`POST` (путь уточнить при переключении; сейчас АИС шлёт на скрипт-маршрутизатор):

```json
{
  "ip_address": "192.168.150.185",
  "port": 8087,
  "username": "admin",
  "password": "admin",
  "autoscale": 2,
  "operation": "weighing"
}
```

- `ip_address` + `autoscale` — legacy-ключ маршрутизации: по справочнику центра определяет объект/весы (старый адрес UniServer этого объекта).
- `username/password` — проверяются по базе центра (не пробрасываются дальше).
- `operation` — НОВОЕ поле: `"weighing"` (брутто) | `"taring"` (тарирование). До подтверждения АИС: отсутствие поля трактовать как `"weighing"`.

## Ответ (центр → АИС)

Успех:

```json
{
  "code": "OK",
  "massa": 43310.0,
  "weighing_datetime": "2026-08-07T15:59:26",
  "unit_meas": "kg",
  "front_image": "/vesy/2026/08/07/913cb979ae034d0eb4748278d9f4cfcf_photo1.jpeg",
  "rear_image": "/vesy/2026/08/07/913cb979ae034d0eb4748278d9f4cfcf_photo2.jpeg",
  "tare": 15300.0,
  "tare_datetime": "2026-06-12T10:21:00",
  "netto": 28010.0
}
```

- Базовые шесть полей — байт-в-байт как в текущей системе (формат даты ISO без зоны, вес числом в кг).
- `tare`/`tare_datetime`/`netto` — НОВЫЕ, только для `operation=weighing`; если действующей тары нет (>3 мес) — `"tare": null, "netto": null, "no_valid_tare": true`.

Ошибки: `code` из перечня `ERR_AGENT_OFFLINE | ERR_SCALE_OFFLINE | ERR_NOT_ZERO | ERR_VEHICLE_TIMEOUT | ERR_UNSTABLE | ERR_CAMERA | ERR_BUSY | ERR_INTERNAL` + человекочитаемое `message` на русском. Семантику см. architecture §4.1. При `ERR_CAMERA` вес возвращается (поля успеха заполнены), code сигнализирует отсутствие снимка.

## Фото

URL постоянные, не протухают. Доступ: заголовок `Authorization: Bearer <сервисный токен АИС>` + IP-allowlist сервера АИС. АИС проксирует фото своим пользователям. Повторное скачивание любых старых фото — в пределах хранения 5 лет.

## События (этап 2, RabbitMQ)

`weighing.completed` — каждое завершённое взвешивание/тарирование, включая досылку офлайн-операций. Существующий брокер организации, отдельный vhost и учётка для весовой системы. Формат сообщения — согласовать с разработчиками АИС (черновик появится здесь).
